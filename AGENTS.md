# dkdc.io

## Overview

Landing page for dkdc.io. Built with [Zorto](https://zorto.dev/) static site generator.

Vibe: simple, speedy, scalable. Full-width hero with animated mesh gradient. Tagline: "Code by Cody."

## Commands

- `zorto preview --open`: Start dev server with auto-open browser (or use `bin/preview`)
- `zorto build`: Build site to `public/`
- `zorto check`: Check for broken internal links

## Styling

Dark mode default with light mode toggle. Color scheme: violet/purple neon + cyan accents. Same theme as dkdc.dev.
